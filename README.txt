Play Game
PENDING - Waiting for more than 1 player.
ROUND 1
init_PREP - 2 Minutes
	All joining players teleport to random start point.
	Create first weapons, armor, heals, etc. 
FIGHT - 1 Minute
	All players teleport to "Arena" for battle. 
	When every player is dead except one (LPS - Last Player Standing), move on to next 	round.
	If more than 1 player is alive when the FIGHT stage ends, the SHOWDOWN stage 	begins. 
SHOWDOWN - 20 Seconds
	Skipped if one player alive in the FIGHT stage. 
	Same rules as the FIGHT stage, more damage, someone player with least health 	automatically dies ("ZAPPED").
ROUND 2+
PREP - 1 Minute
	All players that died in prior FIGHT/SHOWDOWN stage, teleport to random point to 	prepare for the next FIGHT stage. Create better weapons, armor, heals, etc. 
	LPS from the FIGHT/SHOWDOWN stages, in the previous round, stays 	in the arena 	and fights monsters. They are restricted from doing any preparation for the next 	FIGHT stage, but health does reset.
FIGHT - 1 Minute
SHOWDOWN - 20 Seconds

Game ends after any one player is LPS for 3 rounds.
